# Prisha Birthday Website

A static HTML birthday website made for Prisha, with a countdown to 15 May, animated wishes, and a memory gallery using the uploaded `d1.jpeg`, `d2.jpeg`, and `d3.jpeg` photos.

## Pages

- `index.html` - birthday countdown in days, hours, and seconds.
- `cause.html` - animated reasons and wishes for Prisha.
- `last.html` - final birthday memories gallery.

All CSS and JavaScript are inline inside the HTML files, so there are no separate local `.css` or `.js` files required for hosting.

## Preview

Upload this folder to any static host, or open `index.html` in a browser. For local preview, run:

```bash
python -m http.server 8000
```

Then visit `http://127.0.0.1:8000/index.html`.
